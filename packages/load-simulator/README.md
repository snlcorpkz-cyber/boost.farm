# Load simulator (chaotic users)

Скрипт создаёт много реальных пользователей через `POST /auth/verify-code`, заводит фермы, связывает друзей по реф-кодам первых «сид»-аккаунтов, затем долго шлёт **случайные** запросы (полив, ведро, хомяк, чекин, реклама, привет/полив друга, клейм игры и т.д.).

## Зачем нужен `LOAD_TEST_SECRET`

Глобальный лимит API: **120 запросов в минуту с одного IP**. Без обхода симулятор с одной машины упирается в потолок. Если на сервере задан `LOAD_TEST_SECRET`, клиент шлёт заголовок `X-Load-Test-Secret` и **глобальный** лимит для этих запросов отключается (см. `packages/api/src/index.ts`). Лимиты **на конкретные роуты** (например полив) остаются.

**В `.env` API (только для стенда / локалки):**

```env
LOAD_TEST_SECRET=длинный-случайный-секрет
```

**При запуске симулятора:**

```env
LOAD_TEST_SECRET=тот-же-секрет
API_BASE_URL=https://your-api.example.com
```

## Переменные окружения

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `API_BASE_URL` | `http://127.0.0.1:3001` | База API без `/api` (если прокси — укажи URL, который видит Node) |
| `LOAD_TEST_SECRET` | — | **Обязательно**, совпадает с сервером |
| `SIM_USERS` | `80` | Сколько ботов (можно `10000` — долго и тяжело для БД) |
| `SIM_SEED_USERS` | `25` | Сколько первых аккаунтов только с инвайт-кодами (остальные добавятся к ним по коду) |
| `SIM_BOOT_CONCURRENCY` | `20` | Параллельность регистрации |
| `SIM_CHAOS_CONCURRENCY` | `40` | Параллельных «хаотичных» воркеров в фазе нагрузки |
| `SIM_DURATION_SEC` | `120` | Длительность фазы хаоса (сек) |

## Запуск

Из корня репозитория:

```bash
npm install
cd packages/load-simulator && npm install
set LOAD_TEST_SECRET=your-secret
set API_BASE_URL=http://127.0.0.1:3001
set SIM_USERS=500
set SIM_DURATION_SEC=300
npm run simulate
```

Linux/macOS: `export` вместо `set`.

## 10 000 пользователей

Технически: `SIM_USERS=10000`, увеличь `SIM_BOOT_CONCURRENCY` осторожно (нагрузка на БД при INSERT). Имеет смысл гонять со **staging** БД и следить за CPU/connections в Supabase. Ошибки вроде «уже получил чекин» или «ведро пусто» — нормальны, симулятор их игнорирует внутри одного действия.
